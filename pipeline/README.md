# pipeline/

The first edition kept a second, identical copy of the code here. There is now one copy, at the
repository root (see the [main README](../README.md)). This folder keeps two files so the printed
commands still work:

- `pipeline/requirements.txt` installs the root `requirements.txt`.
- `pipeline/run_pipeline.py` runs the root `run_pipeline.py` from the root folder.
